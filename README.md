## `$ whoami`

I'm a **full-stack software engineer and founder** based in Nairobi, Kenya. I design and build scalable products — from ISP billing infrastructure to AgriTech mobile apps — with a sharp focus on solving real, grounded problems across East Africa.

- 🌐 Building **[Uzanet](https://uzanet.co.ke)** — an all-in-one ISP software & API solution for internet providers
- 🏗 Founder of **[SwahiliPro Software Studios](https://founder.swahilipro.com)** — custom software, mobile apps & AI systems
- 🛠 Operating **[Kioo Technologies](https://tech.swahilipro.com)** — web, mobile, blockchain & creative media
- 🎬 Creating animated explainer videos, Blender renders & AI-voiced productions
- 📡 Deeply interested in network infrastructure, automation and Africa-first software
